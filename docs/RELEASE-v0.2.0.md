Windows USB 设备连接状态与外设电量托盘工具。

本版本修复插拔后设备列表更新不及时的问题，并将界面改为黑灰主题、横向无边框设备展示。

### 下载与使用

- 下载附件 `PeripheralPower-0.2.0-win-x64.zip`，解压后运行 `PeripheralPower.exe`。
- 需要 Windows 10 / 11 x64 和 .NET Framework 4.8。
- 更新前先从旧版托盘菜单选择“退出栖电”。
- 若使用登录启动，请在新版设置中重新勾选，使启动项指向新版。
- `Source code` 是源码包，不是可运行程序。

### 更新内容

- 插拔通知触发连接检测，并每 3 秒独立补查设备清单。
- 连接清单与电量查询分开执行，慢电量查询不再阻塞设备列表更新。
- 保留扫描繁忙期间的后续刷新请求，忽略过期电量结果，避免已移除设备重新出现。
- 扩展 USB PnP 发现范围，合并物理设备的复合接口。
- 黑灰主题、横向设备展示，移除卡片边框、宣传口号和大状态面板。

### 支持范围

当前电量读取实现覆盖标准 HID Battery Strength 和部分 Logitech HID++ 2.0 协议。其他设备仍可显示连接信息，但未公开或未适配的电量会显示为未知。发现 USB 接收器不代表能够读取其后设备的型号和电量。

这是预发布版。已通过 31 项协议与逻辑检查、21 项连接监测检查、22 项界面检查，以及托盘和单实例运行检查。实际 USB 清单枚举已验证；具体无线设备的电量兼容性仍需实机测试。插拔展示时延也受 Windows 驱动枚举速度影响。

程序无需管理员权限，不安装驱动，不自动上传诊断信息。当前发布包未进行代码签名。
